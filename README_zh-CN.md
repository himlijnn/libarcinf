### 功能
使用 libarcinf 动态修改 libcocos2dcpp。最新版支持如下功能：
- 自动游玩（游戏内热切换）
- 自动游玩时不保存结果
- 离线全部角色技能
- 离线可切换角色觉醒状态
- 重构视频资源路径
- 修改设置界面
- ……

### 快速开始

项目使用 [Ninja](https://github.com/ninja-build/ninja) 和 NDK r30 构建。

> [!NOTE]
> 本地构建前请修改 CMakePresets.json 和 CMakeLists.txt。
